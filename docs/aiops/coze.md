# 智能体 Coze

## 1. 什么是智能体

智能体是基于大语言模型（LLM）构建的智能应用程序，它能够理解用户意图、执行任务、调用工具，并以自然语言的方式与用户交互。

我们可以把智能体想象成一个**数字员工**，通过以下四个维度来定义它：

### 1.1 人设（Persona/Role）

**定义**：它是智能体的"灵魂"和"身份"。人设决定了 AI 以什么样的口吻说话，拥有什么样的专业背景，以及它的价值观是什么。

**包含要素**：

- 名字
- 职业（如：金牌翻译官、资深程序员）
- 性格特征（如：严谨、幽默）
- 目标任务

**例子**：

- 普通 AI："你好，我是助手。"
- 带有人设的 AI："嘿！我是你的毒舌健身教练。现在是早上 6 点，你居然还没去跑步？别想偷懒！"

### 1.2 回复逻辑（Response Logic/Instructions）

**定义**：它是智能体的"思维导图"或"操作手册"。回复逻辑规定了 AI 在收到指令后，分几步走，避开哪些雷区，以什么格式输出。

**包含要素**：

- 思考步骤
- 约束条件
- 语言偏好

**例子**：

> "在回答用户的编程问题时，你必须：
>
> 1. 先解释原理
> 2. 给出代码块
> 3. 检查代码安全性
> 4. 严禁使用过时的库"

### 1.3 插件（Plugins/Tools）

**定义**：它是智能体的"外接器官"或"工具包"。原生的大模型通常无法联网或获取实时数据，插件则赋予了它与外部世界交互的能力。

**作用**：扩展功能，让 AI 能够查天气、订机票、搜索最新的论文、生成图片等。

**比喻**：就像给智能手机装了不同的 App。

**例子**：一个"旅游助手"智能体，调用了"携程插件"来查询酒店房价。

### 1.4 工作流（Workflow）

**定义**：它是智能体的"标准作业程序 (SOP)"。如果说回复逻辑是口头指令，工作流就是可视化的自动化流程。它通过预设的节点（开始 → 判断 → 处理 → 输出），让智能体处理复杂任务。

**特点**：逻辑严密，适合处理多步骤、高重复性的任务。

**比喻**：就像工厂的生产流水线。

**例子**：

1. **第一步**：抓取用户输入的网页链接
2. **第二步**：提取网页核心文字
3. **第三步**：将文字翻译成中文
4. **第四步**：生成一份 300 字的摘要发送给用户

**Step 2**：选择 Plugin

![选择插件](/.vitepress/public/images/posts/2026/01/2026-01-21-plugin-select.png)

**Step 3**：选择大模型

选择大模型时需要注意以下 3 点：

#### 3.1 Input 配置

![Input 配置](/.vitepress/public/images/posts/2026/01/2026-01-21-input-config.png)

这个一般为上一个 plugin 返回的 response 中的某一项作为大模型的 input。

#### 3.2 系统提示词（System Prompt）

这是在后台配置智能体时，开发者预先写好的指令。它是不可见的，用户在聊天框里看不到，但它时刻控制着 AI 的行为。

**核心作用**：决定"你是谁"以及"你怎么做事"

**包含内容**：

- **角色设定**："你是一位拥有 10 年经验的资深 Python 程序员。"
- **行为准则**："回答必须简洁，严禁使用废话。"
- **技能/工具**："你可以调用搜索插件来获取实时资讯。"
- **负面约束**："不要回答任何与政治敏感相关的话题。"

#### 3.3 用户提示词（User Prompt）

![用户提示词](/.vitepress/public/images/posts/2026/01/2026-01-21-user-prompt.png)

这是用户在聊天窗口中输入的内容。它是动态的、随时变化的。

## 总结

智能体的核心在于四个维度的协同工作：

- **人设**：定义身份和风格
- **回复逻辑**：规范思考和输出
- **插件**：扩展外部能力
- **工作流**：自动化复杂流程

通过 Coze 平台，我们可以快速搭建和部署自己的智能体应用。
