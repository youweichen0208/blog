1. **基础**：理解关系模型、表 / 行 / 列、主键与外键

3. **进阶**：索引原理（B+ 树）、执行计划、慢查询优化
4. **事务**：ACID、隔离级别、锁与 MVCC
5. **实践**：MySQL / PostgreSQL 的使用与运维
