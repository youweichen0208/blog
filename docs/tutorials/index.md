## 实战检查清单

- 每篇教程尽量保留“环境信息、关键命令、验证方式、常见错误”四个部分。
- 命令类文章优先写可复制的最小路径，再补原理和延伸阅读。
- 运维类文章需要明确危险操作，例如防火墙、端口暴露、`kill -9`、证书和密钥权限。
