# 数据结构

欢迎来到数据结构专栏！这里记录了常见数据结构的学习笔记、实现方法和经典问题解析。

## 内容概览

### 基础数据结构
- 数组与字符串
- 链表
- 栈与队列
- 哈希表

### 树形结构
- 二叉树
- 二叉搜索树
- 平衡树（AVL、红黑树）
- 堆
- 字典树（Trie）

### 图结构
- 图的表示
- 图的遍历
- 最短路径
- 最小生成树

### 高级数据结构
- 并查集
- 线段树
- 树状数组
- 跳表

## 学习路线

1. **基础阶段**：掌握数组、链表、栈、队列等基本数据结构
2. **进阶阶段**：学习树、图等复杂数据结构
3. **高级阶段**：了解并查集、线段树等高级数据结构
