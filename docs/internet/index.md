## 快速对比

| 特性 | IPv4 | IPv6 |
|------|------|------|
| 地址长度 | 32 位（约 43 亿） | 128 位（几乎无限） |
| 表示法 | 点分十进制 `192.168.1.1` | 冒号十六进制 `2001:db8::1` |
| NAT | 几乎必须 | 设计上不需要 |
| 配置方式 | DHCP / 手动 | SLAAC / DHCPv6 / 手动 |
| 报头大小 | 20-60 字节（可变） | 固定 40 字节 |
| 内置安全 | 无（IPsec 可选） | IPsec 原生支持 |
| 广播 | 支持 | 不支持（改用多播） |
